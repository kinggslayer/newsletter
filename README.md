# Newsletter: A React-based News Application

**Newsletter** is a modern and dynamic news application that allows users to browse the latest news articles from various categories with features like infinite scrolling, customizable filters, and smooth UI interactions.

## Features

- **Dynamic News Categories**: View top headlines from categories such as Business, Sports, Entertainment, Technology, and more.
- **Infinite Scrolling**: Seamless loading of articles as you scroll, ensuring uninterrupted reading.
- **Responsive Design**: Fully responsive and optimized for different screen sizes.
- **Customizable Country**: Select your preferred country to view localized news.
- **Progress Indicator**: Displays a loading progress bar for better user experience.

## Tech Stack

### Frontend
- **React.js**: Framework for building the user interface.
- **Bootstrap**: For responsive design and styling.
- **React Infinite Scroll Component**: For infinite scrolling functionality.
- **PropTypes**: For validating component props.

### Backend
- **Node.js & Express**: Backend server for fetching news data.
- **NewsAPI**: Fetches top headlines and articles.
